# 読書メモ: Banana X プロンプトパターン集

- **URL:** [Banana X プロンプトパターン集](https://furoku.github.io/bananaX/projects/infographic-evaluation/index.html)

## いつ読むか？

- NotebookLM でインフォグラフィックを生成するとき
- AI にビジュアルデザインの指示を出すとき

## 読書メモ

### 概要

NotebookLM 向けのインフォグラフィック生成プロンプト集。50種類のデザインパターンが用意されており、ワンクリックでコピーして使える。

### 主なカテゴリ

| カテゴリ | 例 |
|----------|-----|
| ミニマル・クリーン | 極細線画、スカンジナビアン、広い余白 |
| ラグジュアリー | アールデコ、金箔、アールヌーボー |
| 和風・伝統 | 浮世絵、水墨画、ケルト模様 |
| サイバーパンク | ネオン、グリッチアート、ホログラム |
| レトロ | Vaporwave、80年代アーケード、ヴィンテージSF |
| モダン・ソフト | クレイモーフィズム、グラスモーフィズム |
| かわいい系 | Kawaii パステル、ペーパーカット |
| テクニカル | 青写真、ターミナル風 |

### 使い方

1. サイトでパターンを選択
2. 「コピー」ボタンでプロンプトをクリップボードに転送
3. NotebookLM に貼り付けて実行

### 各パターンの構成要素

- 配色（HEXコード付き）
- フォント指定
- テクスチャ・質感
- 可読性・階層構造・一貫性のスコア（10点満点）
