## 読書メモ

### 核心となる考え方

Next.js App Router は「サーバーファースト」の設計思想。デフォルトで Server Components を使い、必要な部分だけ Client Components にする。

### 5つの主要テーマ

1. **データフェッチ**: Server Components 内でデータ取得。Request Memoization で重複リクエストを自動排除
2. **コンポーネント設計**: サーバー/クライアントの境界を意識。Composition パターンで柔軟に組み合わせる
3. **キャッシュ戦略**: Full Route Cache、Data Cache、Router Cache の3層構造を理解する
4. **レンダリング最適化**: Suspense でストリーミングレンダリング。段階的にUIを表示
5. **実践知識**: 認証・認可、エラーハンドリングなどの実装パターン

### 重要キーワード

- **Server Components**: サーバーでのみ実行。バンドルサイズ削減
- **Request Memoization**: 同一リクエストの自動キャッシュ
- **Server Actions**: サーバーサイドのデータ操作関数
- **Suspense**: 非同期処理の境界を定義
