## 読書メモ

エムスリーがローコードツール (mabl) から Playwright (TypeScript) へ移行した事例。

**移行理由**

- 「全員 QA」方針で開発チーム全体にテスト開発を広げるため
- CI/CD との親和性とバージョン管理の利便性

**Playwright 構成**

- 言語: TypeScript
- 設計パターン: Page Object Model (Playwright 公式スタイル)

**Claude Code + playwright-mcp の活用**

- playwright-mcp (Microsoft) でページ情報を取得し、Page Object を生成させる
- プログラミング知識が少ないメンバーでも AI との対話でテストコードを作成できる
- 学習コストを下げながらスキル習得も同時に実現
