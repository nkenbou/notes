## いつ読むか？

- Obsidian で個人的な日報や日記を継続したいとき
- Obsidian で蓄積した情報を AI で整理・分析したいとき

## 読書メモ

### 概要

Obsidian で日々の情報を一元管理し、Claude Code で自然言語検索・自動分析を実現する業務アシスタント構築の実例。

### 実践したくなる場面

- 「先週何をしたか」をすぐに振り返りたいとき
- 散在する情報（Slack相談、会議内容、タスク）を一箇所で検索したいとき
- 週次報告や振り返りの作成を自動化したいとき

### 実践に必要なこと

- Obsidian + デイリーノート運用
- Claude Code CLI のインストール
- MCP Tools for Obsidian の設定
- シェル関数の作成（`th` でメモ追記、`obs` でClaude検索）

### ポイント

- thino プラグインでマイクロブログ的に気軽に記録
- Google Meet + Gemini で会議を自動議事録化しデイリーノートに貼付
- Dataview クエリで全ノートの未完了タスクを自動集約
