## いつ読むか？

- TypeScript で DDD の戦術的パターン（値オブジェクト、エンティティ、集約、リポジトリ等）を実装したいとき
- イベントストーミングやドメインモデリングの具体的な手法を学びたいとき

## 読書メモ

### 概要

TypeScript と DDD を組み合わせた API 構築のハンズオンガイド。戦略的設計と戦術的設計の両面をカバー。

### 主要トピック

**戦略的設計**: イベントストーミング、ドメインモデリング、モデル図作成

**戦術的設計**: 値オブジェクト、エンティティ、集約、ドメインサービス、リポジトリ、アプリケーションサービスの実装

**拡張**: ESLint、DI コンテナ、ドメインイベント

### ポイント

- 各パターンの TypeScript 実装例が具体的に示されている
- 約 18 万字の無料コンテンツで網羅的
