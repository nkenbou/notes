## 認知バイアスの例

| バイアス名          | 説明                                              |
| -------------- | ----------------------------------------------- |
| 確証バイアス         | 自分の既存の信念や仮説に合う情報だけを集め、反証となる情報を無視・軽視してしまう        |
| 権威バイアス         | 有名企業や著名人が推奨しているという理由だけで、内容を十分に検討せずに正しいと判断してしまう  |
| バンドワゴン効果       | 多数派の意見や流行に乗ることで安心し、自分で内容を評価せずに正しいと思い込んでしまう      |
| ハロー効果          | ある一点が優れていると、関連しない他の特性まで実際より高く評価してしまう            |
| 現状維持バイアス       | 変化によるリスクを過大評価し、より良い選択肢があっても慣れ親しんだ現状にとどまろうとする    |
| サンクコスト効果       | 過去に費やした時間・費用・労力への執着から、合理的でないと分かっていても選択をやめられなくなる |
| 利用可能性ヒューリスティック | 記憶に残りやすい出来事や最近の事例を過大評価し、統計的な正確さよりも印象で判断してしまう    |
